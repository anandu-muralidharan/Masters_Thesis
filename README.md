# Overview

This repository contains the complete collection of computational workflows, data analysis scripts, and plotting utilities developed during my Master's thesis work focused on Pt/BCN electrocatalyst systems for oxygen reduction reaction (ORR) applications.

The work combines:

- Experimental electrochemical characterization
- XRD and XPS analysis
- Density Functional Theory (DFT) calculations
- Electronic structure analysis
- Durability and kinetic evaluation
- Visualization and publication-quality plotting workflows

The primary objective of this work is to understand how boron and nitrogen co-doping in graphene-derived carbon supports influences:

- Pt-support interactions
- Electronic structure modulation
- d-band center behavior
- Charge transfer characteristics
- Catalytic activity and durability

# Catalyst Systems Studied

The repository primarily focuses on:

- Pt/C
- Pt/BC$_9$N
- Pt/BC$_6$N
- Pt/BC$_2$N

These systems were investigated to understand the effect of BCN composition on Pt nanoparticle dispersion, electronic structure, and ORR activity.
